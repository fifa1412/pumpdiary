# Pump It Up PHOENIX 2 grades and plates

This reference records the score grades and clear plates used for Pump It Up PHOENIX 2. Grade and plate labels below retain their in-game English spelling.

## Grades

Grades are listed from highest to lowest. The score ranges are inclusive.

| Grade | Score |
| --- | ---: |
| SSS+ | 995,000–1,000,000 |
| SSS | 990,000–994,999 |
| SS+ | 985,000–989,999 |
| SS | 980,000–984,999 |
| S+ | 975,000–979,999 |
| S | 970,000–974,999 |
| AAA+ | 960,000–969,999 |
| AAA | 950,000–959,999 |
| AA+ | 940,000–949,999 |
| AA | 920,000–939,999 |
| A+ | 900,000–919,999 |
| A | 800,000–899,999 |
| B | 700,000–799,999 |
| C | 600,000–699,999 |
| D | 500,000–599,999 |
| F | 0–499,999 |

PHOENIX 2 revised the lower grade cutoffs: A+ begins at 900,000, AA at 920,000, and AA+ at 940,000. In PHOENIX 1 the corresponding floors were 825,000, 900,000, and 925,000; its D floor was 450,000 rather than 500,000. The upper grades from AAA through SSS+ retain the PHOENIX 1 thresholds. These revised lower bands are documented by the PHOENIX 2 PUMBILITY reference, which identifies 900,000 as the A+ floor and notes the changed thresholds, and by a current PHOENIX 2 calculator that publishes the complete score bands. The Japanese PIU community wiki's PHOENIX 2 table appears to retain the older lower cutoffs, so it is not used for those entries. ## Plates

Plates are listed from highest to lowest. A plate is awarded only on a stage pass; a run that depletes the life gauge and does not clear the stage has no plate.

| Plate | Condition on a stage pass |
| --- | --- |
| Perfect Game | Every judgment is Perfect. |
| Ultimate Game | No Good, Bad, or Miss judgments (Perfects and Greats only). |
| Extreme Game | No Bad or Miss judgments. |
| Superb Game | No Miss judgments. |
| Marvelous Game | 1–5 Misses. |
| Talented Game | 6–10 Misses. |
| Fair Game | 11–20 Misses. |
| Rough Game | 21 or more Misses. |

The spelling **Marvelous Game** is used in PHOENIX 2 community references and PIU score tools; some fan-wiki tables contain the typo “Mavelous.” The plate names and judgment conditions carry over from PHOENIX 1. PHOENIX 2 references also confirm plates remain part of the result system and that a depleted-gauge clear has no plate.
